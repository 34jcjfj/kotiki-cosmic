## How to read entries

- **Added:** a new feature or capability.
- **Changed:** a change to existing behavior.
- **Fixed:** a bug fix.
- **Security:** a security-related fix or notice. Details may be limited while an issue is being investigated.
- **Known issue:** a confirmed limitation users should know about.

If a change can affect access, data handling, privacy, compatibility, or security, the relevant project page should link to a clear user notice.
